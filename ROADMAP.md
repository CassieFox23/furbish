# Roadmap

This document lists what is planned, in order, and what is not coming. Finished work is in [CHANGELOG.md](CHANGELOG.md). Dates are not promised. This is a hobby project.

## Aims

- standard library only
- script first
- no network
- quiet output
- any model optional and tiny

## Next

- the core: `check`, `fix`, `set` and `split`, and config with per-repo profiles

## Later

- the borrowed word lists from proselint, write-good and the AI-tell phrase lists
- Harper (Apache-2.0) as an optional grammar checker
- a measuring-only experiment with a tiny local editing model (CoEdIT-small/base, Apache-2.0, run on the CPU)

## Not planned

- other platforms: Discord, chat, email
- anything that posts for you
- network features
